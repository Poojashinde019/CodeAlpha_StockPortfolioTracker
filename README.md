Stock Portfolio Tracker 📈

Project Description

This is a simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Programming Internship.

Features

- Add stock details.
- View stock portfolio.
- Calculate total investment.
- Exit the application.

Technologies Used

- Python
- Lists
- Dictionaries
- While Loop
- If-Else Statements
- User Input

How to Run

1. Download the project.
2. Open the project in VS Code.
3. Run the following command:

python stock_portfolio.py

Note

Stock names, quantities, and purchase prices are entered manually. This project does not use live stock market data.
